Echo Path

A path lights up one cell at a time. When it finishes, trace the same path back in order. Each stage adds a step, and the grid grows from 3×3 to 5×5.

How to play
  • Watch the gold cells light up in sequence. Each one touches the one before it.
  • Then tap the same cells in the same order.
  • Clear a stage to go up: the path gets one step longer, and the grid widens at stages 4 and 7.
  • You have three lives. A wrong tap costs one and replays the stage with a new path.
  • Scoring: each correct step earns 10 × stage × combo. Clean stages in a row raise the combo, up to ×5. A miss resets it.
  • Keyboard: arrow keys move, Enter or Space taps, P pauses, R starts over. Pausing mid-preview replays the path when you resume.
  • Your best score stays in this browser only.
